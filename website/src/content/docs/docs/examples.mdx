## Feature implementation

**Documented workflow.**

1. Describe one observable outcome and the checks that show it.
2. Approve the plan at Gate 1.
3. Implement in small steps inside the approved paths.
4. Run the checks, verify, and decide at Gate 2.

Source: <a href={doc('WORKFLOW.md#deliver-one-useful-increment')}>deliver one useful increment</a>.

## Brownfield engineering

**Documented workflow, not qualified.** No brownfield use case has a recorded qualification run.

1. Inspect read-only within named paths; exclude secrets and personal data.
2. Keep the project's own instructions and stricter checks.
3. Record a baseline, including existing uncommitted work. An unchanged pre-existing change caps the result at `PARTIAL`.
4. Stop if the work needs more scope than was approved.

Source: <a href={doc('WORKFLOW.md#read-only-reconnaissance')}>read-only reconnaissance</a> and <a href={doc('RESULT_CONTRACT.md')}>result contract</a>.
