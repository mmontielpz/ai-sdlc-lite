There is one installation method: build a Python wheel from a checkout you have reviewed. No package, plugin, extension or binary is published.

Tested on Ubuntu 24.04. The commands on this page are read from the <a href={doc('docs/QUICKSTART.md')}>canonical quickstart</a>.
