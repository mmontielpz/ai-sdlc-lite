# Brand concepts (provisional)

None is final; the owner decides after visual review.

| Folder | Concept |
|---|---|
| `bound/` | Bounded execution and verification: two brackets around a check. **Provisional default.** |
| `bov/` | Bound, Observe, Verify: three arcs around the change under review. |
| `ascend/` | Progressive autonomy: rising steps under a ceiling. |

Each folder has the symbol and horizontal wordmark for dark backgrounds, light backgrounds and one colour (`currentColor`, black when used alone), and a favicon that follows the browser colour scheme. Teal is `#14B8A6` on dark and `#0F766E` on light.

Wordmark lettering is outlined from [Inter](https://github.com/rsms/inter) (SIL Open Font License 1.1). No trademark search has been done.
