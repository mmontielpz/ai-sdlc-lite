# AI-SDLC Lite roadmap

AI-SDLC Lite is an open methodology and a lightweight reference framework for governed, verifiable agentic software engineering. This page is a short public summary. It sets no dates and authorizes nothing; the [project roadmap](../ROADMAP.md) governs.

**Status:** `2.0.0.dev1`, experimental. No release has been published.

## Available today

- The Bound, Observe, Verify workflow, with two human gates.
- An offline command-line tool that checks, after the work, whether changes stayed within the stated scope.
- An installable Skill for coding agents, and a deterministic test suite run in CI.
- The [official website](https://mmontielpz.github.io/ai-sdlc-lite/) with documentation and brand assets. Publishing it is not a framework release or qualification.

## Before an experimental public release

The [release gates](product/RELEASE_GATES_RECONCILED.md) apply unchanged, including independent evaluation, qualification of any supported agent and platform, validation on unlike use cases, a verified security reporting route and release engineering.

## Research directions

Comparative benchmarking, use across multiple agents and evidence-driven adaptation are research questions, not commitments. An open industry standard is a long-term ambition.

## What is not established

- No benchmark has been run, so no efficiency or productivity claim is made.
- Verification detects problems after execution. It does not sandbox or confine an agent.
- Production readiness, autonomous operation and industry adoption are not claimed.
- Platform and agent evidence is limited to what the [qualification matrix](../QUALIFICATION_MATRIX.md) records.
